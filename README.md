# calen

Календарь занятий репетитора на React, TypeScript и Tailwind CSS.

## Запуск в VS Code

1. Откройте папку `calen` в Visual Studio Code.
2. В меню «Терминал» выберите «Создать терминал».
3. При первом запуске выполните `npm ci`. Если зависимости уже установлены, этот шаг можно пропустить.
4. Выполните `npm run dev` и откройте http://localhost:5173/.

Нужен Node.js 20.19+ или 22.12+ с npm. Команда `npm run build` проверяет типы и собирает проект в `dist`. Для просмотра сборки выполните `npm run preview` при остановленном сервере разработки.

## Работа с календарём

- Нажмите на свободное время, чтобы создать занятие. Пример можно загрузить из пустого календаря.
- Нажмите на карточку, чтобы изменить данные, статус или оплату. Для переноса потяните карточку, для изменения длительности — её нижний край.
- При сохранении или удалении занятия серии выберите, какие записи затронуть.
- Изменение часового пояса влияет на отметку текущего времени и кнопку «Сегодня». Занятия сохраняют указанные календарные дату и время.
- Данные доступны в том же браузере и на том же адресе. Используйте «Экспорт JSON» для резервной копии и «Импорт JSON» для восстановления.

## Одно расписание на компьютере и телефоне

1. Начните с резервной копии, если уже используете календарь. Нажмите «Экспорт JSON» и сохраните файл вне публичного репозитория.
2. В [Firebase Console](https://console.firebase.google.com/) создайте проект на тарифе Spark. Создайте Cloud Firestore Standard в режиме Production, включите Authentication → Email/Password и добавьте своего пользователя в Authentication → Users.
3. В файле `firestore.rules` замените `REPLACE_WITH_OWNER_UID` на UID этого пользователя. Опубликуйте правила через вкладку Rules в Firestore. Доступ к расписанию получит только указанный аккаунт.
4. Добавьте веб-приложение в настройках Firebase. Скопируйте его конфигурацию в формате JSON в переменную `VITE_FIREBASE_CONFIG` файла `.env.local` по примеру `.env.example`. Для проверки перезапустите `npm run dev`. Без этой настройки календарь использует локальный режим.
5. После входа на сайте импортируйте сохранённый JSON, если переносите старое расписание. Импорт заменяет текущее расписание после подтверждения. Откройте сайт на обоих устройствах с одним аккаунтом. Изменения подтягиваются при возврате на страницу либо примерно раз в 15 секунд, пока форма закрыта.

Календарь хранит текстовые записи одним документом Firestore с ограничением в 960 000 байт. Экспорт JSON доступен для резервной копии.

### GitHub Pages

1. Создайте публичный репозиторий `calen`. В Settings → Secrets and variables → Actions → Variables добавьте `VITE_FIREBASE_CONFIG` с JSON-конфигурацией веб-приложения.
2. В Settings → Pages выберите GitHub Actions как источник публикации.
3. Загрузите исходники в ветку `main`. Workflow в `.github/workflows/pages.yml` соберёт и опубликует приложение. Адрес появится в Settings → Pages.
